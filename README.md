# 핑계오피스

상황을 적으면 친구에게 장난으로 보낼 핑계 문서를 만들어 주는 웹앱입니다. 그럴듯한 핑계와 도장을 담아 이미지나 글로 보낼 수 있습니다. 문서는 재미용이며 실제 서류나 증명서로 쓸 수 없습니다.

## 사용하기

1. 상황을 적거나 예시를 고릅니다.
2. **핑계 문서 만들기**를 누릅니다.
3. 문서를 복사하거나 PNG·PDF 파일로 저장합니다.

이름과 도장은 입력 화면에서 바로 바꿀 수 있으며, 도장 5개를 처음부터 모두 사용할 수 있습니다. **팀장·대표·받는 사람·날짜 바꾸기**를 펼치면 결재 정보를 바꿀 수 있습니다. 기본 문서는 결재란과 검토 의견이 있는 사유서이며, 요약 문서로도 바꿀 수 있습니다.

문서·이름·도장·활동 기록은 현재 브라우저에 저장됩니다. **백업 파일 저장**으로 함께 보관하고 다른 기기에서 **백업 불러오기**로 옮길 수 있습니다. 예전에 저장한 문서 전용 백업도 불러올 수 있습니다.

상황의 주요 단어에 맞는 핑계를 고르고, **다른 핑계**를 누르면 방금 본 이유를 피합니다. 상황을 바꾼 뒤 누르면 새 문서를 만들어 이전 문서도 보관합니다. **오늘의 추천**은 같은 날짜에 같은 내용을 보여 줍니다.

## 내 컴퓨터에서 실행하기

Node.js가 필요합니다.

```sh
bun install
bun run dev
```

주요 기능 확인은 `bun run test`, 코드 검사는 `bun run lint`로 실행합니다.

## 배포

`main` 브랜치에 코드를 올리면 GitHub Actions가 앱을 만들고 GitHub Pages에 올립니다.
